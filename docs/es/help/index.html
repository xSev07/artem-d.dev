No se pudo completar la operación

La operación no se completó debido a un error técnico.

Qué significa

En casos poco frecuentes, la base de datos local o el sistema operativo del dispositivo pueden impedir temporalmente que se guarden los datos.

Qué puedes intentar

  • Cerrar y volver a abrir la aplicación
  • Reiniciar el dispositivo
  • Comprobar que haya suficiente espacio de almacenamiento libre en el dispositivo
  • Asegurarte de que esté instalada la última versión de la aplicación

Si el problema persiste

Contacta con el soporte:
support@artem-d.dev

En el correo, es recomendable indicar:

  • modelo del dispositivo
  • versión de Android
  • versión de la aplicación
  • qué acción estabas realizando antes de que apareciera el error
