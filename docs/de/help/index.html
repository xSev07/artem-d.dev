Sprache

Vorgang konnte nicht abgeschlossen werden

Der Vorgang konnte aufgrund eines technischen Fehlers nicht abgeschlossen werden.

Was das bedeutet

In seltenen Fällen können die lokale Datenbank oder das Betriebssystem des Geräts das Schreiben von Daten vorübergehend verhindern.

Was Sie versuchen können

  • Die App schließen und erneut öffnen
  • Das Gerät neu starten
  • Prüfen, ob auf dem Gerät ausreichend freier Speicherplatz vorhanden ist
  • Sicherstellen, dass die neueste Version der App installiert ist

Wenn das Problem weiterhin besteht

Kontaktieren Sie den Support:
support@artem-d.dev

Geben Sie in Ihrer E-Mail nach Möglichkeit Folgendes an:

  • Gerätemodell
  • Android-Version
  • App-Version
  • welche Aktion Sie ausgeführt haben, bevor der Fehler auftrat
