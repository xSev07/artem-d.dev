Privacy Policy

Last updated: 03.07.2026

Developer: Artem D

Contact address: contact@artem-d.dev

1. General Provisions

This Privacy Policy describes how data is processed when using the mobile application. The app is designed with local data storage in mind (offline-first). Financial records and other user-created app data are stored locally on the user's device and are not transferred to the developer.

The app may use third-party services for technical purposes, such as crash and error reporting. These services may process technical diagnostic data needed to detect, diagnose, and fix errors.

2. What data is processed

2.1 Data entered by the user

The user enters the following into the app:

  • financial records (transactions)
  • categories and tags
  • jar names, account names, notes, and other user settings

This data is stored locally on the user's device, is not transferred to the developer, is not copied to the developer's servers, and is not shared with third parties. The developer has no technical ability to access this data.

2.2 Platform technical data

When installing and using the app, the Google Play platform may automatically process technical data such as device information, operating system version, diagnostic data, and crash reports.

Such data is processed by Google services in accordance with their own privacy policy. The developer does not receive the user's personal data from Google.

2.3 In-app purchases

The app may use in-app purchases processed through Google Play. Payment processing is handled by Google's infrastructure. The developer does not receive bank card data, does not store payment information, and does not have access to the user's financial details.

2.4 Crash and error reporting

The app uses Sentry, a third-party error monitoring service, to process crash reports and technical diagnostic data on behalf of the developer.

When an error occurs, the app may send technical diagnostic information to Sentry, such as crash logs, stack traces, app version, operating system version, device model, and other technical details related to the error.

Sentry is configured with default personal data collection disabled. The app does not intentionally send financial records, transaction data, jar names, tags, notes, account names, or other user-created financial content to Sentry.

The developer uses error reports only to improve app stability, diagnose technical issues, and fix bugs.

Because the app does not use accounts or assign user identifiers for error reporting, the developer may not be able to identify and delete a specific user's error reports.

3. Data storage

Financial records and other user-created app data are stored locally on the user's device in the app's database. Deleting the app results in deletion of locally stored data unless the user has created a backup beforehand. The developer does not store copies of this user-created app data and has no access to it.

Technical crash and diagnostic data may be processed by Sentry for error monitoring purposes.

4. Transfer of data to third parties

The developer does not sell user data and does not transfer user-created financial data to third parties.

Financial records, transactions, tags, jar names, notes, settings, and backups are not transferred to the developer or to external servers by the app.

Technical crash and diagnostic data may be processed by Sentry on behalf of the developer for the purpose of detecting, diagnosing, and fixing errors.

5. Backups

If the app provides the ability to create a backup, the backup file is created by the user and saved at their discretion. The developer does not have access to backups.

6. User rights

The user may:

  • delete locally stored app data by deleting the app or clearing the app data in device settings
  • opt out of using in-app purchases
  • contact the developer regarding privacy

Because the app does not use accounts or assign user identifiers for error reporting, the developer may not be able to identify and delete a specific user's error reports.

7. Security

The app does not transmit the user's financial data over the internet. Technical crash and diagnostic data, if sent, is transmitted through a secure connection.

The user is responsible for the security of their device and any backups created.

8. Policy changes

An updated version of the policy is published on the app's official page.

9. Contact information

For privacy-related inquiries: contact@artem-d.dev
