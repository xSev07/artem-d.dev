Политика конфиденциальности

Дата последнего обновления: 03.07.2026

Разработчик: Artem D

Контактный адрес: contact@artem-d.dev

1. Общие положения

Настоящая Политика конфиденциальности описывает порядок обработки данных при использовании мобильного приложения. Приложение разработано по принципу локального хранения данных (offline-first). Финансовые записи и другие пользовательские данные, созданные в приложении, хранятся локально на устройстве пользователя и не передаются разработчику.

Приложение может использовать сторонние сервисы для технических целей, например для отчётов о сбоях и ошибках. Такие сервисы могут обрабатывать технические диагностические данные, необходимые для обнаружения, анализа и исправления ошибок.

2. Какие данные обрабатываются

2.1 Данные, вводимые пользователем

Пользователь самостоятельно вводит в приложение:

  • финансовые записи (транзакции)
  • категории и теги
  • названия кувшинов, наименования счетов, примечания и другие пользовательские параметры

Эти данные сохраняются локально на устройстве пользователя, не передаются разработчику, не копируются на серверы разработчика и не передаются третьим лицам. Разработчик не имеет технической возможности доступа к этим данным.

2.2 Технические данные платформы

При установке и использовании приложения платформа Google Play может автоматически обрабатывать технические данные, такие как информация об устройстве, версия операционной системы, диагностические данные и сведения о сбоях.

Обработка таких данных осуществляется сервисами Google в соответствии с их собственной политикой конфиденциальности. Разработчик не получает персональные данные пользователя от Google.

2.3 Встроенные покупки

Приложение может использовать встроенные покупки, обрабатываемые через Google Play. Обработка платежей осуществляется инфраструктурой Google. Разработчик не получает данные банковских карт, не хранит платёжную информацию и не имеет доступа к финансовым реквизитам пользователя.

2.4 Отчёты о сбоях и ошибках

Приложение использует Sentry — сторонний сервис мониторинга ошибок, который обрабатывает отчёты о сбоях и технические диагностические данные от имени разработчика.

При возникновении ошибки приложение может отправлять в Sentry техническую диагностическую информацию, например отчёты о сбоях, stack trace, версию приложения, версию операционной системы, модель устройства и другие технические сведения, связанные с ошибкой.

Sentry настроен с отключённой отправкой персональных данных по умолчанию. Приложение не отправляет намеренно финансовые записи, данные транзакций, названия кувшинов, теги, примечания, наименования счетов или другой пользовательский финансовый контент в Sentry.

Разработчик использует отчёты об ошибках только для повышения стабильности приложения, диагностики технических проблем и исправления ошибок.

Так как приложение не использует аккаунты и не назначает пользовательские идентификаторы для отчётов об ошибках, разработчик может не иметь возможности найти и удалить отчёты об ошибках конкретного пользователя.

3. Хранение данных

Финансовые записи и другие пользовательские данные, созданные в приложении, хранятся локально на устройстве пользователя в базе данных приложения. Удаление приложения приводит к удалению локально сохранённых данных, если пользователь предварительно не создал резервную копию. Разработчик не хранит копии этих пользовательских данных и не имеет к ним доступа.

Технические данные о сбоях и диагностические данные могут обрабатываться Sentry в целях мониторинга ошибок.

4. Передача данных третьим лицам

Разработчик не продаёт пользовательские данные и не передаёт пользовательские финансовые данные, созданные в приложении, третьим лицам.

Финансовые записи, транзакции, теги, названия кувшинов, примечания, настройки и резервные копии не передаются приложением разработчику или на внешние серверы.

Технические данные о сбоях и диагностические данные могут обрабатываться Sentry от имени разработчика с целью обнаружения, диагностики и исправления ошибок.

5. Резервное копирование

Если приложение предоставляет возможность создания резервной копии, файл резервной копии создаётся пользователем и сохраняется по его выбору. Разработчик не получает доступ к резервным копиям.

6. Права пользователя

Пользователь может:

  • удалить локально сохранённые данные приложения, удалив приложение или очистив данные приложения в настройках устройства
  • отказаться от использования встроенных покупок
  • связаться с разработчиком по вопросам конфиденциальности

Так как приложение не использует аккаунты и не назначает пользовательские идентификаторы для отчётов об ошибках, разработчик может не иметь возможности найти и удалить отчёты об ошибках конкретного пользователя.

7. Безопасность

Приложение не передаёт пользовательские финансовые данные через интернет. Технические данные о сбоях и диагностические данные, если они отправляются, передаются через защищённое соединение.

Пользователь самостоятельно отвечает за безопасность своего устройства и созданных резервных копий.

8. Изменения политики

Обновлённая версия политики публикуется на официальной странице приложения.
