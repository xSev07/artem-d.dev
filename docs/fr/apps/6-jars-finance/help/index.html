Langue

Impossible d’effectuer l’opération

L’opération n’a pas pu être effectuée en raison d’une erreur technique.

Ce que cela signifie

Dans de rares cas, la base de données locale ou le système d’exploitation de l’appareil peut temporairement empêcher l’enregistrement des données.

Ce que vous pouvez essayer

  • Fermer puis rouvrir l’application
  • Redémarrer l’appareil
  • Vérifier qu’il reste suffisamment d’espace de stockage libre sur l’appareil
  • Vérifier que la dernière version de l’application est installée

Si le problème persiste

Contactez l’assistance :
support@artem-d.dev

Dans votre e-mail, indiquez de préférence :

  • le modèle de l’appareil
  • la version d’Android
  • la version de l’application
  • l’action effectuée avant l’apparition de l’erreur
